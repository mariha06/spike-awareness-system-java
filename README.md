Spike Awareness System

A Java console application designed to provide educational resources and quizzes about spike awareness. Originally developed as part of my first-year Software Engineering degree at Anglia Ruskin University, this project has since become an opportunity for me to continue learning, improving my coding skills and applying concepts from my second year.
My aim is to improve the code structure, develop a better understanding of object-oriented programming, and explore more effective ways to organise and manage data. This ongoing development allows me to put what I learn at university into practice while strengthening my programming skills and understanding of software development.

Features:
Resource Library: Stores and displays educational resources.
Keyword Search: Allows users to search for resources using keywords.
Interactive Quiz: Provides multiple-choice questions and calculates the user's score.
Resource Submissions: Allows users to submit resources for review.
Input Validation: Checks user input and validates resource submissions.
File Handling: Saves submitted resources to a text file.
Console Menu: Provides a menu for navigating the application's features.

Technologies and Concepts:
Language: Java
Object-oriented programming (OOP)
Classes, objects, constructors and methods
Arrays and loops
Conditional statements
User input and input validation
File handling
Exception handling
Basic searching and resource management

Project Structure:
Main.java ==> Runs the application and manages the main menu
Resource.java ==> Represents an individual educational resource
ResourceLibrary.java ==> Stores, displays and searches the available resources
Quiz.java ==> Manages the quiz questions, user answers and scoring
Submission.java ==> Handles resource submissions and saves them to a text file.
